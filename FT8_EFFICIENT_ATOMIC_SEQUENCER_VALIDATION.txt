FIELD LOG THAT MOTIVATED THE CHANGE
===================================
The supplied FT8 field log showed:
- 90% gate jobs around 441-571 ms;
- complete-boundary jobs around 583-1133 ms;
- 645-998 cumulative candidates per job;
- GF(2) OSD bursts up to about 219 ms, including many zero-recovery jobs;
- a 420 ms Auto-QSO CQ ranking delay close to the UTC boundary;
- one FT8 frame started late with 153 ms removed from the waveform;
- decodeReady rows reached MainWindow sequentially, so the sequencer could arm
  on one row before all rows from the same completed decoder job were evaluated.

IMPLEMENTED RUNTIME CHANGES
===========================
A. Stop decoding padding / incomplete live slots
- The early gate now requires enough genuinely captured audio, excluding UTC
  pre-padding, to contain at least one complete protocol frame.
- This suppresses the 95-97% zero-candidate gate jobs observed immediately after
  RX restarts near the end of a period.

B. One bounded 90% gate pass
- The gate runs one pass only.
- GF(2) OSD is disabled at the gate.
- Heavy multi-metric recovery is disabled at the gate.
- Boundary/offline decoding retains the complete recovery path.
- Gate candidate cap is reduced without changing its first-pass sync threshold.

C. Do not run later passes on nothing
- If no CRC-valid decode exists, later subtraction/rescan passes stop
  immediately. Candidate pressure alone can no longer trigger pass 2/3 on an
  unchanged noise residual.

D. Candidate-cloud suppression before LDPC
- DT/DF non-maximum suppression is widened from <4 Hz / <80 ms to <=6.5 Hz /
  <=120 ms.
- The strongest local Costas maximum is kept. The frequency radius remains far
  below one FT8 tone spacing, so distinct FT8 signals are not intentionally
  merged.

E. Atomic sequencer batch
- Ft8RxDecoder emits decodeBatchStarted/decodeBatchFinished around each complete
  job result.
- Decode rows remain visible immediately.
- MainWindow queues sequencer-relevant rows and evaluates one best transition
  against one immutable QSO context at batch end.
- Duplicate copies of the same message/frequency are coalesced before the
  sequencer decision.
- Auto-QSO CQ ranking is flushed at batch completion instead of waiting an
  additional 420 ms timer.

F. Never transmit a truncated FT waveform
- skipInitialMilliseconds() is no longer called from MainWindow for FT4/FT8.
- If the audio deadline is already missed, PTT is released, RX remains/returns
  active, and the unchanged message is scheduled for the next selected slot.
- A second hard guard catches deadline loss while the audio backend is opening.
