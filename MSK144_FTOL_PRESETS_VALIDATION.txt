MadModem 0.5.78 — MSK144 F Tol presets

Diagnosis
---------
The former MSK144 UI control labelled "DF" was not the decoded DF value. It sets the decoder search half-width around the selected RX frequency:

    f0 = RX - tolerance
    f1 = RX + tolerance

That is the MSK144 frequency tolerance ("F Tol") concept. The decoded result field/column DF remains the measured frequency offset of an individual decode and is intentionally unchanged.

Changes
-------
- MSK144 control renamed from DF/DF tol to F Tol.
- Free-running 10..500 Hz spin box replaced by fixed presets:
    50 Hz
    100 Hz
    200 Hz
    500 Hz
- Default changed to 200 Hz.
- Selection is persisted as MSK144/fToleranceHz.
- Decoder API/internal state renamed to frequency tolerance terminology.
- MSK144 status/runtime text now reports F Tol.
- Generic Q65 DF control and MSK144 decoded DF column remain unchanged.
- Translation parity preserved for IT/EN/FR/DE/NO/CZ.
