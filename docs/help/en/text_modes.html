Text modes

RTTY: selected station

Select the baud/shift preset and normal or reverse polarity, then place Mark/Space on the signal. The terminal, AFC, macros and contest form refer to this selected pair. Choose a custom preset only when the transmitting station uses different parameters. The selected-station text trail is optional.

RTTY band skimmer

Enable Skimmer and choose Text or CQ calls only beside it. Channels limits simultaneous receivers to 2–16 (default 12). Each acquired pair has independent Baudot letters/figures and character timing. All use the chosen baud, shift and polarity; this is not an automatic detector of mixed RTTY formats.

The scanner covers 100–3500 Hz of received audio. It tracks pair frequency while preserving the shift. Text scrolls vertically beside each pair; CQ view requires two matching callsigns in CQ context. Neighbouring text and Mark/Space traces are kept clear; +N · zoom means some columns need more space. Radio filters, overlapping pairs, QRM and decoding errors limit the result. Use a wider radio filter to receive several stations.

Skimmer output does not select a correspondent, fill or save a QSO, move the rotator or start TX. Click the desired pair and check the selected terminal before using the reply macro. Clear RX, a frequency change, a changed format or missing audio resets the affected tracking. Skimmer text is cleared after local TX. Turning Skimmer off restores the optional selected-station trail.

Macros and contest

The waterfall macro buttons work outside contest mode as well. In Contest, select the contest and verify your exchange before preparing the reply. Check the correspondent and received exchange in the QSO form before logging.

PSK, MFSK and Feld Hell

Select the mode, tune its marker and start RX. Baud rate, filter and AFC controls depend on the mode. Macros use your station identity from Settings.

SSTV image editor

Use Open project / Save project (.mmsstv) to retain editable text and logos. PNG export produces a finished image. Select elements in the list, drag to move, and use Undo / Redo. Fit image shows the whole card; TX preview shows the selected SSTV raster. My callsign and Correspondent are separate fields. Use for SSTV TX prepares the image; start transmission from the main window. Auto mode (VIS) detects a complete valid header and starts the next picture while retaining the previous picture until then. Disable VIS for manual mode selection. Auto sync controls line synchronization independently. WAV analysis can be cancelled.

Adjust a received SSTV image

Open Adjust received image in the Mode tab. Horizontal position rolls the image; Red alignment and Blue alignment register those channels against green. Every change redraws all received rows, during reception and after completion, including Robot and PD. Reset adjustments restores the original received pixels. Saving PNG uses the corrected image. The collapsed panel leaves ordinary RX controls compact. Start RX without synchronization explicitly restarts the image and disables both VIS and line sync; re-enable the two checkboxes for automatic reception.

Save received SSTV images automatically

In Mode, enable Automatically save received images and choose the destination with the folder button. The preference and folder are remembered. By default the option is off; the proposed directory is Pictures/MadModem/SSTV, created on the first save. Completed live or WAV images are written as PNG in the background. Names contain UTC date/time and mode, for example 2026-10-26_183045_Robot36.png; numeric suffixes preserve existing files. The saved pixels are those at completion, including adjustments active then. Later adjustments use Save PNG for a new manual export. Open received-image folder launches the file manager. Success or failure appears in the receive status and runtime log. Accepted jobs keep their original destination even if the option or folder changes, and finish at program close. Received images never replace your own QSL or enter the TX editor.
