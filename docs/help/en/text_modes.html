Text modes

RTTY: selected station

Select the baud/shift preset and normal or reverse polarity, then place Mark/Space on the signal. The terminal, AFC, macros and contest form refer to this selected pair. Choose a custom preset only when the transmitting station uses different parameters. The selected-station text trail is optional.

RTTY band skimmer

Enable Skimmer and choose Text or CQ calls only beside it. Channels limits simultaneous receivers to 2–16 (default 12). Each acquired pair has independent Baudot letters/figures and character timing. All use the chosen baud, shift and polarity; this is not an automatic detector of mixed RTTY formats.

The scanner covers 100–3500 Hz of received audio. It tracks pair frequency while preserving the shift. Text scrolls vertically beside each pair; CQ view requires two matching callsigns in CQ context. Neighbouring text and Mark/Space traces are kept clear; +N · zoom means some columns need more space. Radio filters, overlapping pairs, QRM and decoding errors limit the result. Use a wider radio filter to receive several stations.

Skimmer output does not select a correspondent, fill or save a QSO, move the rotator or start TX. Click the desired pair and check the selected terminal before using the reply macro. Clear RX, a frequency change, a changed format or missing audio resets the affected tracking. Skimmer text is cleared after local TX. Turning Skimmer off restores the optional selected-station trail.

Macros and contest

The waterfall macro buttons work outside contest mode as well. In Contest, select the contest and verify your exchange before preparing the reply. Check the correspondent and received exchange in the QSO form before logging.

PSK, MFSK and Feld Hell

Select the mode, tune its marker and start RX. Baud rate, filter and AFC controls depend on the mode. Macros use your station identity from Settings.
