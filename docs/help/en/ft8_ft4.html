FT4 / FT8

Select a band to tune a connected radio to the standard FT dial frequency. Green marks RX and red marks TX on the waterfall; double-click a decoded line to select the correspondent and prepare the standard message sequence.

QSO timing

During an active QSO, FT8 and FT4 first decode a bounded group around the correspondent's audio frequency. A reply containing both callsigns can therefore reach the sequencer before the rest of the passband has finished. If that focused group misses, normal wideband decoding continues.

Sequence display

The clock shows the current period and time to the next TX. The compact banner distinguishes RX, a message waiting for its slot, the next scheduled TX and a transmission currently on air.

Station and diagnostics

Configure a valid My Call and My Locator in Settings → User/QTH before transmitting. Use Runtime log for slot, decoder, CAT and PTT diagnostics. Analyze WAV decodes a recording without arming PTT or the TX scheduler.

Split Operation

With CAT enabled, Split Operation keeps the sound-card TX tone in the clean 1500–2000 Hz range while preserving the RF frequency selected by the red TX marker. For example, a 900 Hz marker becomes 1900 Hz audio with a −1000 Hz CAT dial shift; 2300 Hz becomes 1800 Hz audio with a +500 Hz shift. Rig uses the transceiver's native split through Hamlib; Hamlib maps the logical TX side onto the radio's actual VFO/bank topology. Fake It retunes the current VFO at each TX/RX transition. If the requested CAT transaction fails, TX is aborted rather than silently falling back.
