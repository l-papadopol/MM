FT4 / FT8

The received table includes Bearing. CQ rows keep CQ colouring, but the dashed red outline marks any decoded valid callsign that is not yet in the ADIF logbook, even when the station is inside another QSO rather than calling CQ. FT TX remains under the UTC scheduler. Rotator tracking is asynchronous and never delays or inhibits FT4/FT8 transmission.

Mandatory station identity

Before moving the rotator or transmitting, configure a valid My Call and My Locator in Settings → User/QTH. If they are missing, MM blocks TX, PTT, Tune, calibration and rotator pointing.

Runtime log

The Runtime log button is shown here in the FT Mode tab, not in Status, so FT timing/CAT/PTT diagnostics stay close to FT controls.

Rotator

Rotator movement is independent from FT TX. Check the rotator endpoint and MOV/RDY lamps only for pointing diagnostics; transmission continues on schedule.

Decoder recovery in 0.5.79

MIND remains removed. FT8 Deep Max restores the classical weak-signal search budgets, Costas/LLR gates, OSD and residual overlap recovery that had accidentally been tied to the old MIND switch. Final acceptance still requires LDPC, CRC, unpacking and message validation. The FT4 core was not changed speculatively; use the headless same-WAV regression command to compare builds on identical recordings.
