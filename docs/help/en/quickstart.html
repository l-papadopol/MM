Quick start

First session

  1. Install the package matching your system, or extract a portable archive. On Linux portable, start AppRun.
  2. Set your callsign and locator in Settings → User/QTH.
  3. In Audio / PTT / CAT select input/output, the real radio model and connection parameters. Test CAT reads, then check PTT and audio routing at a suitable low power.
  4. Choose the mode and start RX. Set the audio level below clipping, then tune the waterfall marker. Keep the computer UTC clock synchronized for FT4/FT8.
  5. Prepare and check the TX message before enabling TX. Stop cancels TX and pending starts.
  6. Use Skimmer in CW or RTTY to monitor several received signals, with Text or CQ display. A narrow radio filter limits the scanned band.
  7. Open the logbook with Ctrl+L. Filter/select contacts for ADIF export, or select the contest edition and review its QSO preview for Cabrillo.
  8. Windows can be resized from edges and corners. Before replacing a portable copy, preserve settings.mad, ADIF logs and recordings.

Updates

At startup MM checks stable releases on l-papadopol/MM on GitHub. Help offers a manual check and a switch to disable startup checks. Drafts, prereleases and versions equal to or older than the running version are ignored. Confirm the download and then confirm closing MM to apply it. Stop TX and automatic operation first. Downloads require a matching package and SHA256SUMS.txt. Managed installations open their native installer; license and system permission dialogs still apply. Portable copies stay portable: a complete backup is kept beside the program folder, settings and logbooks are preserved, and MM restarts after a bounded version check. If that check fails, the helper restores the previous folder. Keep the backup until the update has been tested. Windows keeps the current portable CPU variant; installers choose automatically. Automatic Linux selection supports Ubuntu 24.04 and Fedora 43 only. Starting with source R4, automatic tags such as build-0.6.4-N are also accepted: clear pre-release and enable Latest on GitHub. The tag can stay unchanged. A higher public version is required; another build of the same version does not trigger an update. Older clients need a numeric tag or one manual installation.
