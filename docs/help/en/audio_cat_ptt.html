Audio, PTT and CAT

The Audio / PTT / CAT tab contains audio devices, PTT method, CAT polling, Hamlib rig model and safe tests. CAT test reads frequency and never keys PTT.

FT4/FT8 Split Operation

The Radio/CAT settings offer None, Rig and Fake It. Rig uses the transceiver's native split through Hamlib, which owns the physical VFO/bank mapping; Fake It temporarily retunes the current VFO before TX and restores it after PTT. Both require CAT and keep the generated FT TX audio between 1500 and 2000 Hz by moving the dial in 500 Hz steps.
