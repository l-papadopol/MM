Audio, CAT and PTT

Audio, PTT and CAT

The Audio / PTT / CAT tab contains audio devices, PTT method, CAT polling, Hamlib rig model and safe tests. CAT test reads frequency and never keys PTT.

FT4/FT8 Split Operation

The Radio/CAT settings offer None, Rig and Fake It. Rig uses the transceiver's native split through Hamlib, which owns the physical VFO/bank mapping; Fake It temporarily retunes the current VFO before TX and restores it after PTT. Both require CAT and keep the generated FT TX audio between 1500 and 2000 Hz by moving the dial in 500 Hz steps.

Ports and radio filters

Select the actual Hamlib maker and model, then choose or type the CAT serial port and select a standard baud rate matching the radio. CAT PTT uses that connection; the separate PTT serial port is for RTS/DTR control and is not the CAT model number. Avoid opening the same serial port independently for CAT and serial PTT. Test CAT reads before TX. Receive mode and filter width reported by supported radios inform the display; they cannot restore audio removed by the radio filter. AFSK audio TX and hardware FSK/CW keying are different paths: verify the radio data input and mode routing.
