CW / Morse

CW uses two independent exact-tone receivers centred on the waterfall markers. Left-click selects green RX A; right-click enables or tunes blue RX B. Each receiver has its own terminal, clear button, Auto/manual WPM state, AFC, filter and timing model.

Native decoder: the selected carrier is mixed to complex baseband and converted into one-millisecond soft MARK evidence. A Bayesian timing beam jointly evaluates dots, dashes and element/character/word gaps. Measured durations are never resized or fused; SNR changes confidence only; WPM is a weak hint and a derived display value.

QSB: a low-confidence amplitude collapse is treated as uncertainty rather than an immediate certain space. The decoder may delay commitment, but information completely buried by a deep fade cannot be guaranteed.

Carrier lanes: the full-passband scanner shows persistent carrier labels on the waterfall. It does not stamp decoded letters there. Confirmed text is continuous in the RX A/RX B panes.

Waterfall: the level reference uses the real occupied audio band, so partial-band input or one strong narrow carrier does not turn the whole display orange. The zoom/pan bar is below the frequency labels.

Diagnostics and recording

The Diagnostics view is passive and shows measured envelopes, thresholds, MARK probability, QSB uncertainty, carrier prominence, coherence and the actual filter output. GUI state does not control the decoder.

Use File → Start RX audio recording… (Ctrl+Shift+R) to record the exact normalized mono WAV stream used by the waterfall and decoders.

The standalone native regression checks clean 20/30 WPM messages, a wrong initial WPM hint, short QSB notches, noise-only suppression and two carrier lanes 25 Hz apart. Real on-air recordings remain decisive.
