CW / Morse

Two selected receivers

Left-click the waterfall for green RX A; right-click to enable or tune blue RX B. Each receiver has an independent terminal, clear button, Auto/manual WPM, AFC and receive filter. Auto WPM acquires the signal speed; manual WPM is useful when the speed is known. A filter that is too narrow or off-centre can remove keying information.

Band skimmer

Enable Skimmer in the CW panel and choose Text or CQ calls only alongside it. Up to 16 independent carriers are decoded in the received audio passband from 100 to 3500 Hz. Each has its own automatic timing and frequency tracking. RX A/B remain available.

Text scrolls vertically beside each carrier, with the newest character at the bottom. Columns avoid neighbouring traces and text. If there is insufficient room, +N · zoom reports hidden columns: zoom around the signals to separate them. CQ view requires two matching callsigns in CQ context; a reply alone is not a CQ. A label is an aid, not a verified log entry.

Radio, TX and diagnostics

The skimmer sees only audio passed by the radio. A 250 Hz CW filter cannot supply the whole 3 kHz band; use a wider receive passband for multiple signals, or a narrow filter for one difficult station. USB-D and CW can have different passbands and audio routing. Centre the signal in the actual filter before judging sensitivity.

The six macro buttons use normal text macros or the active CW contest profile. During CW audio TX, the character highlight follows playback progress. Diagnostics show the selected receiver without changing its decisions. File → Start RX audio recording (Ctrl+Shift+R) records the normalized mono input for later analysis. Noise, fading and overlapping signals can still cause missed or incorrect characters.
