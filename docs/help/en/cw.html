RX engine

Choose Native R12 or Neural R13 (experimental) at the top of the CW settings. The choice is saved and applies to RX A and RX B. The band skimmer stays native. Native is the default.

The experimental model was independently trained on generated Morse at 12–36 WPM. Place each marker accurately on its signal. Native bandwidth, AFC and WPM controls are disabled for this engine. Its radio performance remains to be evaluated. Native diagnostic plots and speed estimates continue to monitor the signal; they are not neural confidence scores. Changing engine preserves received text and resets pending decoding. TX audio and serial KEY are selected separately.

Neural R13 includes causal envelope normalization, adapted MM weights and CTC prefix search without a dictionary. The retired CTC and Envelope selections migrate to Neural R13. Native R12 remains the default. R13 improves the earlier neural decoder but does not outperform Native on every tested signal.

CW / Morse

Two selected receivers

Left-click the waterfall for green RX A; right-click to enable or tune blue RX B. Each receiver has an independent terminal, clear button, Auto/manual WPM, AFC and receive filter. Auto WPM acquires the signal speed; manual WPM is useful when the speed is known. A filter that is too narrow or off-centre can remove keying information.

Band skimmer

Enable Skimmer in the CW panel and choose Text or CQ calls only alongside it. Up to 16 independent carriers are decoded in the received audio passband from 100 to 3500 Hz. Each has its own automatic timing and frequency tracking. RX A/B remain available.

Text scrolls vertically beside each carrier, with the newest character at the bottom. Columns avoid neighbouring traces and text. If there is insufficient room, +N · zoom reports hidden columns: zoom around the signals to separate them. CQ view requires two matching callsigns in CQ context; a reply alone is not a CQ. A label is an aid, not a verified log entry.

Radio, TX and diagnostics

The skimmer sees only audio passed by the radio. A 250 Hz CW filter cannot supply the whole 3 kHz band; use a wider receive passband for multiple signals, or a narrow filter for one difficult station. USB-D and CW can have different passbands and audio routing. Centre the signal in the actual filter before judging sensitivity.

The six macro buttons use normal text macros or the active CW contest profile. During CW audio TX, the character highlight follows playback progress. Diagnostics show the selected receiver without changing its decisions. File → Start RX audio recording (Ctrl+Shift+R) records the normalized mono input for later analysis. Noise, fading and overlapping signals can still cause missed or incorrect characters.

The band skimmer runs in a separate worker with a bounded audio queue. Its capacity adapts from 2 to 16 receivers to leave processing headroom. Overload discards only skimmer history, never RX A/B history. The CW status shows the current channel limit and skimmer overrun count.

Open CW transmission in the CW mode panel. Choose Audio tone over SSB/Data for the existing audio method, or Serial KEY (RTS/DTR) for a wired CW keying interface. Select the actual COM port and KEY line, put the radio in CW, and enable BK-IN if no PTT line is selected. The optional other line on the same port provides PTT with configurable lead/tail; KEY and PTT must use different lines. Serial KEY sends no TX audio and bypasses audio-CW CAT mode forcing, so it does not switch the radio to USB-D. WPM, text and contest macros remain shared with audio CW; current-character highlighting follows KEY edges. USB and OS timing do not guarantee full QSK or hardware-keyer accuracy.

A dedicated KEY port keeps CAT available. To share its CAT serial port, first set CAT handshaking to None and force both DTR and RTS OFF in Audio/PTT/CAT. MM closes CAT exclusively during the message and reconnects after the KEY worker closes the port. Stop interrupts a dot/dash wait and attempts KEY/PTT release. Missing release confirmation blocks further TX; reconnect the interface and press Stop to retry OFF only. A timing overrun stops the message instead of sending catch-up bursts. Test wiring and timing on the actual radio before contest use.
