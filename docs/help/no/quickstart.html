Hurtigstart

Første økt

  1. Installer riktig pakke eller pakk ut et portabelt arkiv. På Linux portabel starter du AppRun.
  2. Angi kallesignal og lokator i Innstillinger → Bruker/QTH.
  3. Velg lydinngang/-utgang, faktisk radiomodell og tilkobling i Audio / PTT / CAT. Test CAT-lesing, deretter PTT og lyd med egnet lav effekt.
  4. Velg modus og start RX. Unngå klipping og still markøren. Synkroniser UTC-klokken for FT4/FT8.
  5. Forbered og kontroller meldingen før TX. Stop avbryter TX og ventende starter.
  6. Skimmer i CW eller RTTY overvåker flere signaler med Tekst eller CQ. Smalt radiofilter begrenser søkebåndet.
  7. Ctrl+L åpner loggboken. Filtrer/velg for ADIF; velg konkurranseutgave og kontroller QSO-forhåndsvisning for Cabrillo.
  8. Endre vindusstørrelse fra kanter og hjørner. Bevar settings.mad, ADIF-logger og opptak før en portabel kopi erstattes.

Oppdateringer

Ved oppstart sjekker MM alle publiserte utgivelser på l-papadopol/MM, også forhåndsversjoner. Latest-merket har ingen betydning; utkast utelates. Høyere offentlig versjon prioriteres, deretter høyere distribusjonsbyggnummer innen samme versjon. Installert eller eldre bygg tilbys ikke igjen. Hjelp gir manuell kontroll og innstilling for oppstartskontroll. Denne venter til automatiske operasjoner er ferdige. Tilbudet viser installert og tilgjengelig versjon/bygg og markerer forhåndsversjoner. Bekreft nedlasting og deretter lukking av MM for installasjon. Stopp TX og automatikk først. Riktig pakke og SHA256SUMS.txt kreves. Administrerte installasjoner åpner installasjonsprogrammet. Portable kopier beholder sikkerhetskopi, innstillinger og loggbok; versjon og bygg kontrolleres før omstart, med tilbakeføring ved feil. Windows beholder portabel CPU-variant; installasjonsprogrammet velger automatisk. Linux støtter Ubuntu 24.04 og Fedora 43. Arbeidsflyten registrerer byggidentiteten automatisk: Fremtidige bygg kan forbli forhåndsversjoner uten Latest eller endring av tagger. Installer 0.6.4 manuelt én gang hvis den gamle sjekkeren ikke finner den. Deretter finner den nye sjekkeren senere publiserte bygg.
