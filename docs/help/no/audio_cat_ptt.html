Lyd, CAT og PTT

Audio / PTT / CAT-fanen inneholder lydenheter, PTT-metode, CAT-polling, Hamlib-rigmodell og trygge tester. CAT-testen leser frekvens og aktiverer aldri PTT.

FT4/FT8 Split-operasjon

Radio/CAT-innstillingene tilbyr Ingen, Rig og Fake It. Rig bruker radioens native split via Hamlib, som håndterer fysisk VFO/bank-kartlegging; Fake It stiller midlertidig om gjeldende VFO før TX og gjenoppretter den etter PTT. Begge krever CAT og holder generert FT TX-lyd mellom 1500 og 2000 Hz ved å flytte radiofrekvensen i 500 Hz-trinn.

Porter og radiofiltre

Velg riktig Hamlib-produsent og modell, deretter CAT-port og en standard baudrate som samsvarer med radioen. Porten kan også skrives inn. CAT-PTT bruker denne tilkoblingen; separat PTT-port er for RTS/DTR og er ikke CAT-modellnummeret. Unngå å åpne samme port uavhengig for CAT og seriell PTT. Test CAT-lesing før TX. Rapportert modus og filterbredde støtter visningen, men gjenoppretter ikke filtrert lyd. AFSK-lydsending og maskinvarebasert FSK/CW-nøkling er ulike signalveier: kontroller datainngang og lydruting.
