Tekstmoduser

RTTY: valgt stasjon

Velg forhåndsinnstilling for baud/skift og normal eller omvendt polaritet, og plasser Mark/Space på signalet. Terminal, AFC, makroer og konkurranseskjema gjelder dette paret. Bruk egendefinerte verdier bare ved andre parametere. Tekstsporet for valgt stasjon er valgfritt.

RTTY-båndskimmer

Aktiver Skimmer og velg Tekst eller Bare CQ-kallesignaler. Kanaler begrenser samtidige mottakere til 2–16, med 12 som standard. Hvert par har egen Baudot-bokstav/tall-tilstand og tegntiming. Alle bruker valgt baudrate, skift og polaritet; blandede RTTY-formater gjenkjennes ikke automatisk.

Søket dekker mottatt lyd fra 100 til 3500 Hz og følger parenes frekvens uten å endre skiftet. Tekst ruller loddrett; CQ-visning krever to like kallesignaler i CQ-sammenheng. Nabotekst og Mark/Space-spor holdes fri. +N · zoom betyr at noen kolonner trenger mer plass. Radiofilter, overlappende par, QRM og dekodingsfeil begrenser resultatet. Bruk bredere radiofilter for flere stasjoner.

Skimmeren velger ikke motstasjon, fyller ikke ut eller lagrer QSO, flytter ikke rotatoren og starter ikke TX. Klikk ønsket par og kontroller terminalen før svarmakroen. Slett RX, frekvens- eller formatendring og manglende lyd nullstiller berørt sporing. Skimmertekst slettes etter lokal TX. Når Skimmer slås av, blir det valgfrie tekstsporet for valgt stasjon tilgjengelig igjen.

Makroer og konkurranse

Vannfallsmakroene virker også utenfor konkurranser. Velg konkurransen og kontroller egen utveksling før svar. Kontroller motstasjon og mottatt utveksling før logging.

PSK, MFSK og Feld Hell

Velg modus, still markøren og start RX. Baudrate, filter og AFC avhenger av modus. Makroene bruker stasjonsdata fra Innstillinger.

SSTV-bilderedigering

Åpne / Lagre prosjekt (.mmsstv) bevarer redigerbar tekst og logoer. PNG-eksport lager det ferdige bildet. Velg og dra elementer; bruk Angre / Gjør om. Tilpass bildet viser hele kortet; TX-forhåndsvisningen viser valgt SSTV-format. Eget kallesignal og motstasjon er separate felt. Klargjør bildet i redigeringen og start sending i hovedvinduet. Automatisk VIS gjenkjenner et komplett gyldig hode og starter neste bilde; det forrige vises inntil da. Slå av VIS for manuelt modusvalg. Auto sync styrer linjesynkronisering separat. WAV-analyse kan avbrytes.

Justere et mottatt SSTV-bilde

Åpne Juster mottatt bilde i Modus-fanen. Vannrett posisjon ruller bildet; rødt og blått justeres mot grønt. Hver endring tegner alle mottatte linjer på nytt, under og etter mottak, også Robot og PD. Nullstill justeringer gjenoppretter de opprinnelige mottatte pikslene. PNG lagrer det korrigerte bildet. Panelet kan foldes sammen. Start RX uten synkronisering starter bildet på nytt og slår av både VIS og linjesynkronisering; slå på begge avkrysningsboksene igjen for automatisk mottak.

Lagre mottatte SSTV-bilder automatisk

Aktiver automatisk lagring i Modus og velg målmappe. Valg og mappe huskes. Valget er av som standard; foreslått mappe er Bilder/MadModem/SSTV, opprettet ved første lagring. Ferdige live- og WAV-bilder lagres som PNG i bakgrunnen. Navnet inneholder UTC-dato, tid og modus; talltillegg beskytter eksisterende filer. Pikslene ved fullført mottak lagres, med justeringene som da var aktive. Bruk Lagre PNG for senere justeringer. Åpne mappe starter filbehandleren. RX-status og logg viser resultatet. Allerede godtatte jobber beholder målmappen og fullføres ved avslutning. Mottatte bilder holdes atskilt fra eget QSL-kort og TX-redigering.
