Journal et carte

Le journal ADIF regroupe les contacts de tous les modes avec QSO. Recherchez et filtrez par indicatif, bande, mode, locator ou intervalle UTC, puis exportez tous les résultats ou seulement les lignes choisies.

Envoi des QSO par UDP : dans Réglages → Journal, activez l’envoi vers le serveur UDP et indiquez l’adresse et le port de destination (127.0.0.1:2237 par défaut). Après l’ajout réussi du QSO au journal ADIF local, MadModem envoie un message UDP ADIF journalisé compatible WSJT-X/JTDX. Un échec UDP n’annule jamais l’entrée locale.

La carte QSO peut afficher un fond en ligne ou local, la grille Maidenhead, les stations et les trajets depuis votre QTH. Un seul bouton Calques choisit les éléments visibles. Le locator sélectionné peut aussi devenir la cible du rotateur.

Exporter une sélection ou un concours

Ouvrez le journal avec Ctrl+L ou depuis le panneau FT. Filtrez, sélectionnez les lignes voulues et utilisez Exporter la sélection pour un sous-ensemble ADIF ; choisissez filtrés/tous uniquement si nécessaire. Pour Cabrillo, choisissez l’export de concours et l’édition par nom et dates. La liste provient des QSO reconnus ; les sessions d’une même édition sont réunies. Vérifiez l’aperçu, excluez les lignes inutiles et corrigez les échanges manquants ou les affectations ambiguës avant de sauvegarder. Les données concours, date, mode et échange doivent être correctes : l’export ne les invente pas.

Le soulignement reconnaît le format d’un indicatif ; les couleurs reflètent le journal local, pas une validation QRZ. Sélectionnez un indicatif dans le texte RX ou le formulaire QSO pour l’afficher dans le panneau QRZ en bas à droite. Ouvrez sa page QRZ ou connectez un compte avec accès XML QRZ pour les détails. Seul le nom d’utilisateur est enregistré : le mot de passe et la session restent en mémoire jusqu’à la fermeture de MM. Les recherches sont asynchrones et mises en cache dix minutes. Les données QRZ ne confirment ni le décodage ni la position actuelle et ne modifient jamais le QSO ou le rotateur.
