CORRECTIONS VERIFIED
--------------------
- Mid-stream discriminator reset anchors the next run to the live timestamp.
- No synthetic multi-second SPACE can start at timestamp zero.
- First sample-rate initialization does not create an extra clean restart.
- A real sample-rate change still performs exactly one restart.
- RX B activation no longer resets an already-clean tracker a second time.
- Frozen/pre-lock micro-runs are filtered before temporal submission and log output.
- Each committed character retains the exact Morse pattern used for its decision.
- Established timing accepts adaptation only when short and long pair members
  indicate a consistent common speed change.
