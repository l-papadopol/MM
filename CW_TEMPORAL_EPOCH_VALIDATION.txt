MadModem 0.5.78 — CW TEMPORAL EPOCH
Validation date: 2026-08-05

PURPOSE
-------
This experimental checkpoint addresses one specific live CW failure: two
operators alternate on the same selected RF lane with substantially different
keying scales. The previous Bayesian-beam decoder retained a common dit/dah
clock and adapted an established clock only gradually, so the reply could be
classified with the preceding operator's geometry.

IMPLEMENTED SCOPE
-----------------
Only the native live CW receive path was changed:

- CwMorseBeamDecoder: local and weak continuity temporal models may coexist.
- CwRelativeTimingDecoder: explicit temporal epochs and abrupt common-scale
  change detection from a centred short/long MARK pair.
- CwRelativeTimingTask: asynchronous BeginEpoch command.
- SelectedToneCwTracker: a centred acquisition pair starts a fresh temporal
  epoch; WPM is display metadata and no longer selects the audio bandwidth.
- CwNativeRegression: direct and complete live-path same-lane operator-change
  cases.

AudioEngine, waterfall/OpenGL, CW transmitter, FT8/FT4 and other modes were not
modified.

CAUSAL COMPARISON ON IDENTICAL SYNTHETIC LIVE AUDIO
---------------------------------------------------
Input delivered through SelectedToneCwTracker at 48 kHz, same carrier 1437 Hz:

  operator A: "CQ CQ", 30 WPM
  operator B: "QTH ROMA", 14 WPM
  no tracker reset between operators

Result compiled against the prior CW_BAYESIAN_BEAM source:

  CQ CQ T TTTT T T

Result compiled against CW_TEMPORAL_EPOCH:

  CQ CQ QTH ROMA

This comparison uses the same signal generator, block size, carrier frequency,
noise levels and live tracker API. It is not a claim of over-the-air success;
the user's live RF test remains decisive.

LIMITATIONS / FALSIFICATION CONDITIONS
--------------------------------------
- A fresh temporal scale requires an informative short/long pair. A prefix made
  only of equal-length MARKs cannot uniquely establish scale immediately.
- The explicit change detector currently requires a common geometric scale
  outside 0.76..1.30 and short/long scale agreement within 20 percent.
- A strong leading MARK that arrives before PSD centring is retained only as a
  reversible probe and replayed after later confirmation.
- This checkpoint is disproved if, in live RF, a same-frequency reply at a very
  different speed still inherits the previous operator's timing or if normal
  single-operator CW regresses materially.
